# دامنه محصول

نسخه جدید modular monolith، PostgreSQL، React/Vite و storage خصوصی دارد. featureهای سازمان از identity سراسری و عضویت scoped استفاده می‌کنند. دو حالت hosted و self_hosted از همین code/image ساخته می‌شوند؛ Kubernetes یا microservice جزو این دامنه نیست.

قابلیت‌های جاری: پروژه/قالب/چرخه، تسک و workflow با تصمیم versioned/idempotent، برد/فهرست/گانت/تقویم، فیلد سفارشی، زیرتسک/چک‌لیست/وابستگی، زمان و ظرفیت، داشبورد، عضو/تیم، صورت‌جلسه، فایل نسخه‌دار با تأیید مشتری/داخلی، گفتگو و فایل/صوت/فوروارد/mention/draft، حضور/تایپ/اعلان، HR و مالی با مجوز مستقل، onboarding/invite/account/session، تنظیم سازمان، طرح دستی و اپراتور، export و جستجوی scoped، لندینگ/lead/SEO، بسته نصب/TLS/upgrade/backup و metric خصوصی.

حدود مهندسی: فایل تا ۲۰MiB، درخواست وابسته به feature دارای pagination تا ۱۰۰ رکورد؛ UI انتخاب‌های بزرگ را با جستجو/صفحه‌بندی انجام می‌دهد. quota همه نسخه‌ها و پیوست‌های بایگانی را حساب می‌کند. حد عضو/فضا و moduleهای طرح در DB و transaction کنترل می‌شوند؛ کاهش سقف اطلاعات را حذف نمی‌کند. مقدار اولیه quota تصمیم مهندسی است، قیمت یا طرح تجاری نیست.

مهمان فقط پروژه دارای grant و فایل همان پروژه را می‌بیند؛ HR، مالی، صورت‌جلسه و گفتگوی داخلی مجوز مهمان ندارند. مدیر سازمان به‌صورت خودکار مجوز مستقل HR/مالی نمی‌گیرد. اپراتور ظرفیت/lead هیچ عضویت محتوایی دریافت نمی‌کند. اصلاح role، لغو grant و نشست در درخواست بعدی و تحویل realtime بررسی می‌شود.

مرحله بعد از پذیرش توسعه، پولیش UI است. قیمت، پرداخت/SMTP واقعی، نام و دامنه نهایی، متن حقوقی تأییدشده و SLA به تنظیم ناشر وابسته‌اند؛ در نسخه بدون تنظیم، ادعای فعال بودن آنها نمایش داده نمی‌شود. import واقعی، انتشار روی سرور زنده، DNS یا پیام‌رسانی بیرونی در این کار انجام نشده است.
