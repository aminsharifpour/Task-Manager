# مرجع طراحی مشترک شکف و شکوفلو

در ۲۰۲۶-۱۰-۱۳ کاربر مخزن [Shekoflow](https://github.com/aminsharifpour/Shekoflow) را به‌عنوان مرجع تطبیق سایدبار، کامپوننت‌ها و فونت معرفی کرد. مبنا commit `cf1504d236c804bf57737d4c005fcb77b50fdb7c` است. نام این محصول همچنان از PRODUCT_NAME می‌آید؛ نام محصول مرجع به آن تحمیل نشده است.

منابع بررسی‌شده در مرجع: `apps/web/src/app/App.tsx`، `styles.css`، `ui-polish.css` و `heroui-theme.css`. CSS مرجع چند لایه override دارد؛ مقادیر نهایی light theme مبنای تطبیق قرار گرفتند.

| بخش | مقدار مشترک |
|---|---|
| فونت | IRANYekan Rounded، فایل‌های WOFF خود مخزن مرجع |
| primary / hover | #205a49 / #174637 |
| متن / متن فرعی | #24473b / #617b70 |
| سطح / سطح فرعی | #ffffff / #edf5ef |
| خط دور | #dce9df |
| سایدبار | سفید، عرض ۲۶۸px، آیکن‌های lucide ۱۹px، نشان Sparkles |
| انتخاب ناوبری | #ebf8f4، خط داخلی سبز، وزن ۷۰۰ |
| کنترل‌ها | فونت ۱۴px، فرم با گوشه ۱۲px، دکمه با گوشه ۱۰px |
| کارت / بنر | گوشه ۱۶px، بنر نعنایی و تصویر خود مرجع |

هشت فایل فونت مستقیماً به‌صورت binary از `apps/web/src/assets/fonts/iranyekan-rounded` مرجع استخراج شدند و در `apps/web/public/fonts/iranyekan-rounded` قرار گرفتند. هیچ درخواست runtime به GitHub یا سایت برند وجود ندارد. وزن‌های ۱۰۰، ۳۰۰، ۴۰۰، ۵۰۰، ۷۰۰، ۸۰۰، ۹۰۰ و ۹۵۰ مشخص‌اند؛ برخلاف مرجع، Black و ExtraBlack با ExtraBold روی وزن ۸۰۰ تداخل ندارند. خانواده فونت در index.css و پوسته جدید تنظیم شده و Tahoma فقط fallback است.

تصاویر dashboard/tasks از `apps/web/public/images/page-banners` همان commit هستند و به‌صورت binary کپی شدند. محتوای ماژول‌های پروژه، تیم، HR و مالی متعلق به این محصول است؛ ساختار دسترسی و داده از محصول مرجع کپی نشده است. تمام فرم‌ها، دکمه‌ها، کارت‌ها، پیام‌ها و برد ماژول‌های منتقل‌شده از سبک مشترک استفاده می‌کنند. لندینگ و صفحات باقیمانده هنوز پیاده نشده‌اند.

سایدبار موبایل در عرض حداکثر ۸۰۰px به drawer تبدیل می‌شود؛ بستن با backdrop، Escape و انتخاب بخش، بازگشت focus و محدود کردن Tab به سایدبار فعال پیاده شده‌اند. ناوبری پنهان از دسترس صفحه‌کلید خارج است.

بررسی واقعی مرورگر: build و test:browser، بارگذاری هشت وزن از document.fonts، خانواده فونت input، عرض سایدبار، موبایل ۳۶۰/۷۶۸، دسکتاپ ۱۴۴۰، RTL، نبود overflow افقی و مسیرهای ماژول‌ها. تصاویر واقعی با داده مصنوعی در `validation/screenshots/foundation-workspace-1440.png`، `modules-board-1440.png` و `shekoflow-sidebar-360.png` ذخیره شده‌اند.

مشاهده اولیه shekof.com و تصاویر `brand-reference-1440.png` برای سابقه محفوظ‌اند؛ مقادیر موقت Tahoma، سبز #153a24 و زمینه کرم قبلی دیگر مبنای پوسته فعال نیستند.
